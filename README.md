# ✨ PuzzleSync

A collaborative, real-time jigsaw puzzle for friends. Open a link, solve together.

**Stack:** vanilla HTML/CSS/JS · Node.js · Express · Socket.io

## Run locally

npm install
npm run dev

Then visit http://localhost:3000
